Inteligencia artificial

Esta IA ya usa la llave guardada en tu Cloudflare. No tienes que pegar nada.

El de arriba se usa para la charla rápida. Este se usa para investigaciones, archivos, cuentas y documentos. Puedes poner varios separados por coma (si falla uno, sigue con el siguiente). Si dejas ambos vacíos, Mitca usa sola la lista de modelos NVIDIA.







Se guardan solo en este dispositivo. Si sale error de modelo, cambia el nombre por uno vigente de tu proveedor. Puedes pegar varias llaves del mismo proveedor separadas por coma o espacio: si una se queda sin cuota, la app usa la siguiente.


¿Cómo consigo la llave?

Gemini (gratis):


  1. Entra a aistudio.google.com con tu cuenta de Google.
  2. Toca Get API key y luego Create API key.
  3. Copia la llave y pégala arriba.


Claude (de pago):


  1. Entra a console.anthropic.com, crea cuenta y agrega saldo.
  2. En API Keys crea una llave (empieza con sk-ant-).
  3. Elige Claude arriba, pega la llave y usa un modelo vigente, por ejemplo claude-sonnet-5-5.


Groq, OpenRouter, Mistral, Cerebras, SambaNova o DeepSeek:
  1. Groq: console.groq.com, sección API Keys.
  2. OpenRouter: openrouter.ai/keys.
  3. Mistral: console.mistral.ai, sección API keys.
  4. Cerebras: cloud.cerebras.ai. SambaNova: cloud.sambanova.ai.
  5. DeepSeek: platform.deepseek.com (de pago, muy barata).
  6. NVIDIA: build.nvidia.com, crea cuenta, elige un modelo y toca Get API Key (empieza con nvapi-). Copia el nombre exacto del modelo (por ejemplo meta/llama-3.3-70b-instruct) en «Modelo».
  7. Otra: cualquier servicio compatible con OpenAI; escribe su dirección terminada en /v1 y el nombre del modelo.
La llave es como una contraseña: no la compartas ni la subas a GitHub.

Memoria


Dile “recuerda que...” y lo guarda. Se envía a la IA en cada mensaje: no guardes contraseñas ni datos de tarjetas.


    



    


    Búsqueda en internet
    


    Los saludos y la charla normal responden al instante, sin buscar. Busca solo con noticias, clima, precios o cuando le dices “busca…”. Si dices “investiga…” o “con fuentes”, hace una investigación más larga. Las fuentes aparecen plegadas debajo de la respuesta.
    

    Archivos
    



    Pídele “hazme un Excel con mi presupuesto” o “redacta una carta en Word” y aparece un botón para descargarlo. Sirve para documentos sencillos; los largos gastan más créditos de la IA.
    


    Claude arma documentos más largos y ordenados. Necesita que hayas guardado antes tu llave de Claude (elígelo arriba una vez). Para platicar sigues con tu IA de siempre.
    



    Si tu IA responde que ya no hay cuota, la app prueba sola con este modelo, luego con tus otras llaves y otras IA que hayas guardado y, al final, con Claude (si guardaste su llave).
    


    Saludos y charla corta van a Groq (rápido, gasta menos cuota). Investigaciones, archivos, cuentas y mensajes largos usan tu IA principal. Si Groq falla, Mitca vuelve sola a tu IA principal. Clima y hora: datos de Open-Meteo.com; tipo de cambio: Frankfurter (Banco Central Europeo).
    


    Si una IA se queda sin cuota, Mitca prueba con las otras que tengas configuradas. Con la puerta segura, las llaves reales quedan en Cloudflare y no en este celular.
    

    Puerta segura (llaves en Cloudflare)
    



    Con el token puesto, las llaves se manejan solas desde Cloudflare y esta pantalla ya no te las pide. Sin token, Mitca usa las llaves guardadas en este celular.
