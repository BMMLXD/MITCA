Inteligencia artificial

Se guardan solo en este dispositivo. Si sale error de modelo, cambia el nombre por uno vigente de tu proveedor.

¿Cómo consigo la llave?

Gemini (gratis):

  1. Entra a aistudio.google.com con tu cuenta de Google.
  2. Toca Get API key y luego Create API key.
  3. Copia la llave y pégala arriba.

Claude (de pago):

  1. Entra a console.anthropic.com, crea cuenta y agrega saldo.
  2. En API Keys crea una llave (empieza con sk-ant-).
  3. Elige Claude arriba, pega la llave y usa un modelo vigente, por ejemplo claude-sonnet-5-5.

Groq, OpenRouter o Mistral (gratis):

  1. Groq: console.groq.com, sección API Keys.
  2. OpenRouter: openrouter.ai/keys.
  3. Mistral: console.mistral.ai, sección API keys.

La llave es como una contraseña: no la compartas ni la subas a GitHub.

Personalidad

Al cambiar de personalidad se borra la charla en pantalla para que no se mezclen los estilos. Tus recuerdos se conservan.

Voz

El plan gratis da unos 10 minutos de voz al mes, según su sitio. Si se acaba o falla, cambia sola a la voz del celular y vuelve a ElevenLabs en cuanto se pueda.

¿Cómo consigo la llave de ElevenLabs?
  1. Crea una cuenta gratis en elevenlabs.io.
  2. Entra a tu perfil y busca API keys.
  3. Crea una llave, cópiala y pégala arriba.
  4. Toca Cargar mis voces y elige una que suene bien en español.

Activación por voz

Separadas por coma. Con “Activar por voz” prendido, al oír una de estas frases te contesta la personalidad que tengas activa (lo que digas junto con la frase también cuenta). Si no te entiende, mira en la pantalla principal cómo escribió tu voz (“Escuché: ...”) y agrega esa forma aquí.

Memoria

Dile “recuerda que...” y lo guarda. Se envía a la IA en cada mensaje: no guardes contraseñas ni datos de tarjetas.

    Búsqueda en internet

    Sirve para noticias, clima o datos actuales. Con Gemini gratis tiene límites diarios; con Claude cada búsqueda tiene costo (unos $10 USD por 1,000, revisa el precio vigente). Si da error, apágala.

    Archivos

    Pídele “hazme un Excel con mi presupuesto” o “redacta una carta en Word” y aparece un botón para descargarlo. Sirve para documentos sencillos; los largos gastan más créditos de la IA.

    Claude arma documentos más largos y ordenados. Necesita que hayas guardado antes tu llave de Claude (elígelo arriba una vez). Para platicar sigues con tu IA de siempre.

    Si tu IA responde que ya no hay cuota, la app prueba sola con este modelo y, si también falla, con Claude (si guardaste su llave).

    Respaldo

    Guarda tus recuerdos y ajustes en un archivo para no perderlos si cambias de celular o borras los datos del navegador.

    Revisar que todo funcione

    Prueba el micrófono, las voces y tu llave en este celular. Te pedirá permiso para usar el micrófono.
